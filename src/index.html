Key Design Decisions
FPP ≥ 85 to auto-close
Conservative bar — 15% residual threat probability too high to dismiss. All closures auditable.
Confidence separate from FPP
Two independent signals. FPP = noise likelihood. Confidence = evidence quality. They move independently.
30-min rolling cluster window
Matches attacker lateral-movement timelines. Fast enough for campaigns; broad enough for slow recon.
Local ATT&CK bundle
Air-gap / SCIF safe. Zero latency. Version-pinned to v15 for reproducible assessments.
PII masking at MCP layer
Prevents operator names, coordinates, personnel IDs leaking into workspace artefacts or reports.
Never abort on feed failure
Malformed satellite CSV must not block SIEM alerts from being actioned. Partial ingest + logged failures.
